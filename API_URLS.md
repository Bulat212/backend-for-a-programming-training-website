API сервера позволяет управлять пользователями, постами, комментариями и пользовательскими проектами. Ниже представлено описание доступных эндпоинтов и их функций.

1. **/users (GET, POST)**
   - **GET**: Возвращает список всех пользователей. Входные данные отсутствуют. Выходные данные — JSON с перечнем пользователей.
   - **POST**: Создает нового пользователя. Входные данные — JSON с полями name и email. Выходные данные — JSON с созданным пользователем.

2. **/posts (GET, POST)**
   - **GET**: Возвращает список всех постов. Входные данные отсутствуют. Выходные данные — JSON со списком постов.
   - **POST**: Создает новый пост. Входные данные — JSON с полями title, body и user_id. Выходные данные — JSON с созданным постом.

3. **/comments (GET, POST)**
   - **GET**: Возвращает список комментариев. Входные данные отсутствуют. Выходные данные — JSON с перечнем комментариев.
   - **POST**: Создает новый комментарий. Входные данные — JSON с полями post_id, body и user_id. Выходные данные — JSON с добавленным комментарием.

4. **/user_projects (GET, POST, PUT)**
   - **GET**: Возвращает список пользовательских проектов. Входные данные отсутствуют. Выходные данные — JSON со списком проектов пользователя.
   - **POST**: Создает новый пользовательский проект. Входные данные — JSON с project_id. Выходные данные — JSON с данными созданного проекта.
   - **PUT**: Обновляет информацию о пользовательском проекте. Входные данные — JSON с изменяемыми полями (code, is_published, earned_stars, language). Выходные данные — JSON с обновленным проектом.

5. **/user_projects/{id}/end_project (PUT)**
   - **PUT**: Завершает проект пользователя и устанавливает дату завершения. Входные данные отсутствуют. Выходные данные — JSON с обновленным статусом проекта.

6. **/user_projects/start_project (POST)**
   - **POST**: Начинает новый проект для пользователя при соблюдении условий. Входные данные — JSON с project_id. Выходные данные — JSON с созданным проектом или сообщением об ошибке.
